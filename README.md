# Lost & Found Campus

A web-based Lost and Found Management System for college campuses.

## 📌 About the Project

Lost & Found Campus helps students report lost items, report found items,
search for items, and delete item records when they are no longer needed.

## 🚀 Features

- Report Lost Items
- Report Found Items
- View Lost Items
- View Found Items
- Search Lost and Found Items
- Delete Items
- Form Validation
- SQLite Database
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
- Git & GitHub

🔎 How It Works
User reports a lost or found item.
Item information is stored in the SQLite database.
Users can view all lost and found items.
Users can search for an item.
Items can be deleted when required.
